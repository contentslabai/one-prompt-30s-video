# 30초 타다닥 영상 만들기

이 폴더(Kinetic 30s Starter)는 이미 돌아가는 판이다. 처음부터 새로 짜지 말고, 있는 파일을 고쳐서 만든다.

## 파일 지도
- `scripts/gen_timeline.py` → `src/timeline.json` : 장면 표(장면 id · 시작 · 끝 · 조각이 붙는 시각). **그림과 소리가 같이 읽는 단 하나의 표.**
- `src/Viewer.tsx` : 장면 그리기. 맨 위 `TEXT` 칸 = 화면 글자. `renderScene` 의 `case` = 장면 id.
- `scripts/mix_sfx.py` : 같은 표로 효과음을 붙이고 -14 LUFS 로 맞춤.
- `scripts/compose.py` : 다 만든 화면을 노트북 · 모니터 바탕 안에 넣어 세로 릴스로.

## 순서 (사용자의 주제 한 줄을 받으면)
1. **장면 표** — 주제를 21장면 안팎으로 나눈다. 박 = 0.5초. 장면 하나 = 1~2박(긴 3D 장면만 3~4박). 마지막 4초는 끝 장면(브랜드 · 한 줄 · 단추). `gen_timeline.py` 의 `SC` 표를 고치고 돌린다.
2. **글자** — `Viewer.tsx` 의 `TEXT` 를 주제에 맞게 바꾼다. 한 화면에 낱말 1~3개. 영어 큰 글자 + 한국어는 이름 · 핵심 한 낱말만.
3. **장면 그림** — 새 장면이 필요하면 기존 컴포넌트(`Word` · `Drop` · `Typewriter` · `Grid9` · `Bars3D` · `Domino3D` …) 하나를 복사해 바꾼다. 조각은 반드시 `sc.pieces[k]` 시각에 붙게(`age(sc, k, t)`), 다른 시계를 만들지 않는다.
4. **미리보기** — `npm run still`(한 장) · `npm run preview`(앞 5초 · 절반 크기)로 보고 고친다.
5. **렌더 · 소리 · 합성** — `npm run render` → `python scripts/mix_sfx.py --video out/viewer-4k.mp4` → (바탕이 있으면) `python scripts/compose.py --bg … --quad …`.

## 통과 기준 (끝났다고 말하기 전에 직접 확인)
- 길이 = `timeline.json` 의 `T` 초 · 60fps · 3840×2160(화면 영상).
- **빈 화면 0** : 장면 머리에서도 그림이 바로 있다(다음 장면 첫 0.22초는 앞 장면과 겹침). 시각 6곳(1 · 5 · 10 · 15 · 20 · 25초)을 still 로 뽑아 눈으로 본다.
- **그림 = 소리** : 효과음 개수 = `timeline.json` 조각 수(`mix_sfx.py` 가 찍는 hits 숫자).
- 글자가 화면 밖으로 넘치지 않는다(긴 낱말은 `size` 를 줄인다).
- 소리 -14 LUFS(±0.3) — `mix_sfx.py` 가 마지막 줄에 찍는다.
- 남의 영상 · 음악 · 글꼴 파일을 키트 폴더에 넣어 공유하지 않는다(각자 받은 것은 각자 폴더에서만).

## 주문 잘 받는 법
- 사용자가 숫자를 안 주면 기본값(30초 · 60fps · 0.5초 박 · 21장면)으로 하고, 무엇을 기본값으로 했는지 한 줄 알린다.
- 「예쁘게」 같은 말은 숫자로 바꿔 되묻지 말고 먼저 한 판 만들어 still 6장을 보여 준다.
- 고칠 때는 장면 id 로 말한다(「bars 장면 막대를 더 길게」).
